# HelioCone · Solar Operations

태양광 운영 레포트 작업실, 현장 점검, 문서 보관함을 제공하는 정적 웹앱입니다.
실측 데이터 연결 없이 **가상 시연 데이터**로 동작합니다.

## 실행

프로젝트 폴더에서 다음 명령을 실행하고 `http://127.0.0.1:4173/#home`를 엽니다.

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

빌드나 런타임 패키지 설치가 필요하지 않습니다. 기존 GitHub Pages의 루트 배포 구조를 그대로 사용할 수 있습니다.

## 인터랙티브 인트로

첫 진입(`/` 또는 `#home`)에는 The Solar Perspective 인트로가 열립니다. 워크스페이스 시작/입장 버튼으로 `#studio`에 진입하고, 내부 로고 또는 인트로 보기 링크로 돌아갈 수 있습니다. 기존 `#studio`, `#sites/B`, `#archive` 직접 링크는 계속 동작합니다.

- Canvas 2D에 원근 투영으로 그린 태양광 패널, 지형, 지지대, 그림자
- 06:00–18:00 장면 시간 슬라이더와 아침·낮·노을 프리셋
- 버튼으로 바꾸는 카메라 시점, 데스크톱 포인터에 반응하는 미세 시차
- 화면을 벗어나거나 업무 화면에 들어가면 렌더링 중단
- reduced-motion 설정에서는 시차와 전환 애니메이션을 줄임
- 실제 현재 날짜/한국 시계와 시연용 장면 시간을 구분
- 직접 작성한 그래픽이며 실제 현장의 발전량이나 태양 위치를 계산하는 시뮬레이터가 아닙니다.

UI UX Pro Max의 `Immersive / Interactive Experience` 패턴과 에디토리얼 타이포 가이드를 참고해 구현했습니다. 스킬의 완성형 사이트 템플릿을 복제한 것은 아닙니다.

## 변경 사항

- 딥그린·라임 색상, 직접 작성한 태양 궤도 SVG, 새 로고와 문서 디자인
- 데스크톱 사이드바, 태블릿 아이콘 탐색, 모바일 하단 탐색
- 가상 현장 요약, 점검 우선순위, A4 미리보기와 확대 기능
- 보관함 검색, 일간·주간 필터, 검색 초기화와 빈 상태 안내
- 포함 항목에는 일사량 그래프와 점검 기록만 표시. 운영 요약·수신 현황은 항상 포함
- `Asia/Seoul` 기준 오늘 날짜와 초 단위 시계. 자정 또는 백그라운드 복귀 때 날짜 갱신
- 오늘을 포함한 최근 15일의 가상 자료와 최근 7일 주간 레포트
- 기존 저장 키 유지. 예전 문서는 기존 UTC+8 표기를 유지하고 새 문서는 KST 사용
- 키보드 포커스, 폼 오류 연결, 접근성 이름, 동작 줄이기 설정 지원

현재 시계는 접속 기기의 시간을 한국 시간대로 변환합니다. 별도의 서버 시각 동기화는 없습니다.
저장 문서는 브라우저의 localStorage에 보관됩니다. 도메인이나 브라우저를 바꾸면 별도 보관함을 사용합니다.
새 날짜의 점검 상태는 그날 작성한 점검 기록으로 판단합니다.

## 검증

```sh
node --check desk.js
node --check model.js
node --check entry.js
node --test tests/model.test.cjs
```

모델 테스트는 KST 자정, 연말 날짜 경계, 자료 기간, 주간 집계, 필수 항목 유지, 과거 CSV 시간대 및 수식 이스케이프를 확인합니다.

브라우저에서 375 / 768 / 1024 / 1440px 너비의 가로 넘침 여부, 모바일 인트로, 장면 프리셋·키보드 슬라이더·시점 전환, 업무 화면 왕복, 오늘 날짜, 선택 항목을 모두 꺼도 필수 요약 유지, 레포트 발행·저장 및 보관함 검색·종류 필터·검색 초기화를 확인했습니다. 콘솔 오류는 없었습니다.
CSV 다운로드 완료와 실제 PDF 저장의 브라우저 검증은 완료되지 않았습니다. CSV 생성 로직은 모델 테스트를 통과했습니다.
